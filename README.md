# CorelDRAW 2020+ 快捷键查询

一个纯 HTML 快捷键查询工具，**无需安装任何依赖**，手机和 PC 浏览器均可直接打开使用。

## 使用方式

直接打开 `index.html` 即可，或将文件传到手机浏览器中。

## 功能

- **136 条快捷键**，覆盖 11 个常用分类
- 适用于 CorelDRAW 2020、2021、2022、2023、2024 及更高版本
- **实时搜索**：按快捷键名称、按键组合或功能描述筛选
- **分类筛选**：文件、编辑、视图、绘制、排列、文本、效果等
- **深色模式**：跟随系统主题自动切换
- **触控优化**：移动端单手操作适配
- **离线可用**：单文件，不依赖网络

## 快捷键分类

| 分类 | 说明 |
|------|------|
| 文件操作 | 新建、打开、保存、导出、导入 |
| 编辑操作 | 撤销、复制、再制、全选 |
| 视图控制 | 缩放、平移、全屏、网格标尺 |
| 选择操作 | 挑选工具、Tab切换选择 |
| 绘制工具 | F5手绘、F6矩形、F7椭圆、F8文本等 |
| 排列与组织 | 群组、合并、锁定、顺序、对齐 |
| 形状与对象 | 形状工具、轮廓、填充、转曲线 |
| 文本操作 | 格式、编辑、字号、拼写 |
| 效果 | 调和、立体、透视、PowerClip |
| 窗口与面板 | 泊坞窗、管理器、快捷键F2-F11 |
